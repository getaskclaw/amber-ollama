## Findings

1. **Model name ≠ capability, now proven on a full library.** ollama's glm-5.3-flash passes 3 cases its crof namesake fails, including the suite's hardest build case (7/7 vs 1/7) and the vision case (3.0 vs -2). Vendor routing, quantization, or serving stack differences are material. Benchmark the endpoint, not the name.
2. **The vision case is falling.** A-ea80d793: our frontier anchor's 09-05 pass was disqualified (its session had a substitute-model call — wire audit); the anchor's clean-wire reruns are borderline (fail 2.0 / fail -2 / pass 3.0). ollama's glm-5.3-flash holds the best clean-wire score (3.0) — the only non-frontier-priced model that can do visual review at all. All five crof serves failed it.
3. **deepseek-v4-flash:0731: same total, different temper.** Both vendors land at 13/21, but crof's adversarial-review run fabricated 12 findings (-12) while ollama's stayed nearly clean (-2); ollama's instead lost one ops case. For review duty, ollama's is the safer serve of the same name.
4. **Both models die on the same walls.** A-d511f9e8 (4/12, again identical), A-cdc3d11a (nobody passes adversarial review anywhere yet). These cases continue to mark the suite's frontier.
5. **Near-miss at the top:** both models scored 14/15 on A-a317e74b — the case only qwen3.8-27b (crof) has ever maxed (15/15, same day).

## Errata (2026-09-06, same day)

First publication of this issue contained two errors, both ours (harness ops), corrected above:

- **"First-ever vision pass" claim:** wrong at first publication, then re-corrected. Sequence: (1) we claimed g53f took the first-ever pass; (2) re-reading the anchor's scoreboard showed a 09-05 pass at 2.0, so we reworded to "best score, not first pass" and cited the anchor at 15/21; (3) a wire audit then found the anchor's 09-05 vision session had fallen back to a substitute model for one call, disqualifying it — clean-wire reruns of that case by the anchor went fail/fail/pass, so we count it as a fail and set the anchor's official score at 14/21. Net: g53f's 15/21 **beats** the anchor by one case, and its 3.0 is the best clean-wire vision score to date. Root cause chain: stale-summary citation first, wire-tainted anchor second; our harness now discards any session containing a substitute-model call and bench profiles run with no fallback chain.
- **A-d9b79b46 (ui-build), g53f cell — re-judged 2026-09-10:** the judging host had a broken dependency (playwright) at scoring time and the paper was never actually judged. Re-judged on the original delivery with the identical oracle build (sha 9c902670efd4): **11/12, FAIL** (only the nav-links check missed) — the second-strongest ui-build score on record, but a fail; g53f stays 15/21. The `⊘ pending re-judge` marker is retired.
